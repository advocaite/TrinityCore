# The models behind the launcher's AI BOTS tab (in the repack: repack\bot-bridge\models.txt). All free, all from Ollama.
#
#   <tier> = <Ollama model> | <download GB> | <graphics card memory GB it needs, 0 = none> | <answers at once>
#
# One line per tier: the model the tab suggests for that size of graphics card. "Answers at once" is both the AI program's
# --workers and Ollama's OLLAMA_NUM_PARALLEL (the launcher sets it when it starts Ollama). Each one keeps its own context in
# the card's memory, so small cards keep 2. A tier missing here keeps the launcher's own default.
#
#   extra = <Ollama model> | <download GB> | <graphics card memory GB it needs, 0 = none> | <answers at once> | <note> | <note in Russian>
#
# More models for the tab's Model list (the player can also type any other Ollama model name there). The note is shown
# beside the name (the Russian one in the Russian launcher), keep it short. This file is UTF-8. A model bigger than the PC's graphics card is still listed, marked as too big.
# Change a line, then press "Apply the change" in the tab. Launchers older than 0.1.36 read only the tier lines.
